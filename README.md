# Nexa Business Intelligence Dashboard

## 📊 Project Overview

Nexa Business Intelligence Dashboard is an interactive business analytics
application built using Python, Pandas, Plotly, and Streamlit.

The dashboard helps analyze sales, product, customer, and regional
performance through interactive visualizations, KPIs, filters, and
automated business insights.


Local URL: http://localhost:8501
Network URL: http://10.86.138.244:8501


## 🚀 Features

- Executive business overview
- Sales performance analysis
- Product intelligence
- Customer insights
- Regional performance analysis
- Interactive date, region, category, and sales-channel filters
- Revenue and profit KPIs
- Order and customer analysis
- Average Order Value (AOV)
- Monthly revenue and profit trends
- Top product analysis
- Customer value analysis
- Regional performance analysis
- CSV file upload
- Data validation
- Uploaded dataset preview
- Reset to default dataset
- Automated business insights

## 🛠️ Technology Stack

- Python
- Pandas
- Streamlit
- Plotly
- HTML
- CSS
